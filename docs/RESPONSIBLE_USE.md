# Responsible public-source research

Use PH0MBER only with legitimate authority and respect source terms, privacy, intellectual-property restrictions, and applicable law. Do not bypass authentication, paywalls, CAPTCHAs or private profiles. Do not import leaked credentials, private contact details, precise residential locations or nonpublic personal information. Do not speculate about sensitive personal characteristics or private relationships.

Review ambiguous identities manually. A username, common name, collaborator mention or name search hit does not establish identity or a private relationship. Sources may contain outdated, inaccurate or malicious self-reported material. Findings preserve provenance and uncertainty; “verified” describes resource retrieval, not proof of a person's identity.

Reports are private and local by default. Directories are created mode 0700 and files mode 0600 on POSIX; Windows uses the user's inherited ACLs. Reports contain personal research and are not encrypted. Exports inherit destination directory permissions; protect them appropriately. Report routes are read-only; the local wiki is always in admin mode, with profile and collection management available without a login. Management forms require Origin checks and CSRF tokens. The localhost server accepts loopback Host headers, and exposes only allowlisted report files. Other processes on your computer may reach localhost. Do not proxy it publicly. There are no analytics. AI research is enabled by default for the wiki command and sends investigation context and public evidence to the configured provider. Use --no-ai or --offline to disable AI.

Use `--omit location` or another top-level subject field before collecting; omission also removes that field when resuming. Do not use omitted identifiers in other free-text fields. For erasure use `phomber reports delete ID --yes` and `phomber cache clear --yes`, and remove separately exported copies. Generated JSON embeds investigation input and evidence; review before sharing. Cache redaction cannot guarantee the removal of every personal detail from arbitrary biography text.

Historical Git archives contain old configuration data. The distributable Python ZIP excludes the known credential-bearing configuration. Git history and working-tree historical files are intentionally unchanged; rotate previously committed credentials and assess repository history separately.
