Keep exact-name publication candidates out of biography/timeline until subject-specific linkage exists; expose per-work attribution, give mixed discovery responses zero identity marks, and filter stale legacy prose while preserving evidence/revisions.

- Add weighted cross-source matching, evidence/publisher deduplication, source-linked marks and bounded same-subject working hypotheses across professional sources. Add local text-based PDF extraction and whole-document chunking.
- Add `email ADDRESS` for masked syntax/mail-domain DNS checks with an own-details/authorized-subject notice. Track company workflows, privacy cleanup/address exposure and verified-owner breach services as TODO, not shipped features.

- Combine API and web evidence in AI planning and gap reviews, extract every fetched page, read supplied resources directly and follow evidence-linked supported profiles through bounded local adapters. Explain automatic resource matching, exclude rejected identities from synthesis/biographical summaries and prevent candidate names from renaming handle-only reports.

- Simplify the getting-started guide and add a documentation index. Align reference guides, website and wiki About text with the 0.0.2 command, storage, grouping and deletion behavior.

- Use `phomber find` as the primary research command, with a positional name shortcut. Keep `wiki` as an unadvertised compatibility alias.

- Automatically group repeated research runs into profile versions using platform-specific supplied/reviewed profile IDs or matching supplied names and college/work context. Preserve manual separations, explain grouping decisions and migrate old catalogs with backups and profile-link aliases.

- Render readable CLI output by default across commands; preserve explicit `--format json` for scripts. Suppress routine npm notices in the checkout.
- Improve command and wiki search with multiword matching, supplied context, partial names, visible results and server-rendered wiki filtering.
- Support confirmed report deletion in the wiki, direct CLI and interactive terminal, with stale-revision protection and markers preventing deleted-ID reuse.
- Redact omitted email addresses from new web and PDF snapshots and DeepSeek chat prompts. Recover profile catalog locks after confirmed writer exits.

- License Gen2 source, documentation and the website under MIT. Preserve original license terms for historical Python files and the unchanged legacy ZIP.

- Use the same home workspace for installed, NPX and checkout commands on macOS, Linux and Windows. Reports, settings, cache and saved credentials are shared; `PHOMBER_HOME` still selects an isolated workspace.
- Show the resolved workspace in `config`. Session-only key storage is now an explicit `PHOMBER_EPHEMERAL_KEY` preference, independent of the installation method.
- Remove em dashes from project text, CLI output, website and wiki templates.

## Gen2 - 0.0.1

Initial Node.js/npm release of PH0MBER Gen2.

- TypeScript/Node.js runtime with interactive and direct command execution, guided investigations and six legacy scanner equivalents.
- Public-source collection with bounded pagination, retries, request budgets, cancellation and interrupted-run recovery.
- Local investigation wiki with article browsing, evidence excerpts, analyst reviews, collections and profile organization.
- Separate identity/claim assessments, stale-review detection, preserved revisions, hash-verified source snapshots and portable exports.
- Optional DeepSeek research with explicit source-only/offline modes, persistent preferences, citation validation and provider-call/output limits.
- DeepSeek-only CLI collection with `--ai-only`, priority for supplied handles/institution context and exclusion of known contact-broker pages before fetching.
- Local full-text search, focused command help and fresh-install package checks.
- Self-contained GitHub Pages project website at phomber.s41r4j.in, linked from the local wiki.

Historical Python releases remain preserved separately. Gen2 0.0.1 is a local research tool; identity matching and factual claims require analyst review. Broad registry connectors, PDF ingestion and authenticated team case management are outside this release.
